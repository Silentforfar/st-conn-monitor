# 连接监视器（st-conn-monitor）

SillyTavern 扩展：在页面上实时显示 AI 生成请求的死活。

做成 App / 反代部署后，终端里看不到后端日志、生成卡住时也不知道连接是死是活——这个扩展把请求状态直接画在你眼前。

## 功能

- **状态球**：悬浮在页面上，绿＝数据在流入（连接活着）、黄＝短暂无新数据、红＝长时间无数据疑似断流。可拖动，自动贴边不出屏，空闲时可以藏起来。
- **请求历史**：点状态球展开面板，记录每次生成的完整过程。
  - **失败记录可展开**：状态码、错误码、原因（如 `VERTEX_UPSTREAM_FAILED`）、接口原始返回，一眼看出为什么 502。
  - **成功记录也可展开**：首字节时间、总耗时、数据量、**token/s 速度**（用酒馆自带的分词器真实统计，不是估算），以及返回内容开头——能发现「HTTP 200 但内容为空/报错」这种假成功。
- **阈值可调**：等待响应多久算黄/红、流式无新数据多久算黄/红，面板和设置页都能改。
- **不自动置底**（可选开关）：生成结束后视口停在最新消息开头，而不是被顶到最底下。流式/非流式统一由开关控制，兼容假流式。
- 卡顿时可闪烁标签页标题提醒（后台切走也能注意到）。

## 安装

1. 下载本仓库（Code → Download ZIP，解压到 `public/scripts/extensions/third-party/st-conn-monitor`），
   或在扩展管理里用 `https://github.com/Silentforfar/st-conn-monitor` 安装
2. 启用扩展，页面上会出现状态球

## 说明

- 纯前端扩展，只包装 `fetch` 观察请求，不修改、不拦截任何生成逻辑
- token 速度调用酒馆的 `getTokenCountAsync`，分词方式与你平时看到的 token 数一致
- 界面跟随酒馆主题色，支持毛玻璃
